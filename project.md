# Промпт для разработки CRM Барбершопа на Laravel 13

Этот документ содержит структурированный промпт для ИИ (ChatGPT, Claude, Gemini), который поможет сгенерировать архитектуру и код для CRM системы барбершопа.

---

## Контекст задачи
**Роль:** Senior Full-stack Developer.
**Стек:** Laravel 13 (PHP 8.4+), Tailwind CSS, Livewire (Volt), MySQL/PostgreSQL.
**Локализация:** Полностью на русском языке (`lang/ru`).

---

## Промпт для ввода в ИИ

### Заголовок: Разработка CRM для Барбершопа с интеграцией SMS Eskiz.uz

**Инструкция:**
Разработай backend и frontend для системы управления барбершопом на **Laravel 13**. Система должна поддерживать онлайн-запись, управление мастерами и автоматические SMS-уведомления.

#### 1. Модель данных (Migrations & Models)
Создай миграции со следующими связями:
- **Barber**: `id, name, specialization, photo_path, schedule (json), is_active`.
- **Service**: `id, name, price, duration_minutes`.
- **Client**: `id, name, phone (format: 998XXXXXXXXX), last_visit_at`.
- **Appointment**: `id, client_id, barber_id, service_id, scheduled_at, status (pending, confirmed, completed, cancelled), notified_30min (boolean)`.

#### 2. Функционал записи (Booking Flow)
- Реализуй публичную страницу записи на **Livewire (Volt API)**.
- Пользователь должен:
    1. Выбрать услугу.
    2. Выбрать барбера.
    3. Выбрать доступное время (проверка занятости в `Appointments`).
    4. Подтвердить номер телефона.

#### 3. Интеграция SMS (Eskiz.uz)
- Создай класс `App\Services\SmsService` для работы с API **Eskiz.uz**.
- Реализуй авторизацию через JWT с кэшированием токена (Laravel Cache), чтобы не запрашивать его при каждой отправке.
- Методы: `sendSms($phone, $message)`.

#### 4. Автоматизация и уведомления (Scheduling)
Настрой задачи в `routes/console.php` (или новом формате Laravel 13):
- **Напоминание за 30 минут:** Каждую минуту проверять записи, до которых осталось ровно 30 минут. Если `notified_30min == false`, отправить SMS: *"Напоминаем, вы записаны к [Barber] на [Time]. Ждем вас!"*.
- **Удержание клиента (Retention):** Раз в сутки проверять клиентов, чей `last_visit_at` был ровно $N$ дней назад (сделай $N$ настраиваемым параметром в `.env`). Отправить SMS: *"Прошло [N] дней с вашего визита. Пора обновить стрижку!"*.

#### 5. Административная панель
- Простой интерфейс на Tailwind для просмотра списка записей на сегодня.
- Возможность изменения статуса записи (Завершено / Отменено).

#### 6. Технические требования (Laravel 13 + PHP 8.4)
- Используй **Property Hooks** для форматирования атрибутов моделей (например, телефон или цена).
- Используй анонимные миграции.
- Весь интерфейс (кнопки, ошибки, статусы) должен быть на **русском языке**.
- Настрой `config/app.php` на `timezone => 'Asia/Tashkent'` и `locale => 'ru'`.

## Как использовать этот файл
1. Скопируйте текст выше.
2. Вставьте его в чат с ИИ.
3. После генерации кода проверьте файл `.env` на наличие ключей:
    - `ESKIZ_EMAIL=`
    - `ESKIZ_PASSWORD=`
    - `RETENTION_DAYS=21`
