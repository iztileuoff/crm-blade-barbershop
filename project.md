Prompt: Dashboard "Касса" для Barbershop CRM
Objective: Создать главную панель управления (Dashboard) для администратора/кассира на Laravel 13.

1. Логика расчетов (Backend)
Реализуй контроллер DashboardController, который собирает статистику за текущий день (используя timezone => 'Asia/Tashkent'):

Общие показатели (Summary):

total_appointments: Общее количество записей на сегодня.

confirmed_amount: Сумма цен всех услуг (Service->price) для записей со статусом completed или confirmed.

pending_count: Количество записей, ожидающих подтверждения.

Статистика по барберам (Barber Performance):

Список всех активных барберов.

Для каждого барбера: количество его записей на сегодня и общая сумма выручки от его услуг.

2. Интерфейс (Frontend - Tailwind + Livewire)
Создай страницу resources/views/livewire/admin/dashboard.blade.php:

Сетка карточек (Top Stats): Крупные карточки с общим количеством записей и итоговой суммой в кассе за день.

Таблица барберов: Список мастеров с колонками: "Имя", "Записей сегодня", "Выручка".

Стиль: Современный, чистый интерфейс в темных или светлых тонах (на выбор ИИ), полностью на русском языке.

3. Технические детали (Laravel 13)
Используй Eloquent Eager Loading (with(['barber', 'service'])), чтобы избежать проблемы N+1 запросов при расчете суммы по каждому барберу.  

Для фильтрации по дате используй: whereDate('starts_at', today()).  

Реализуй автоматическое обновление данных на странице (Livewire polling) раз в 60 секунд.
